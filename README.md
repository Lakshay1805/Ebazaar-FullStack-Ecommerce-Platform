# E-Bazaar

A full-stack MERN E-Commerce application.

## Features

- JWT Authentication
- Email Verification
- Password Reset
- Refresh Tokens
- Admin Dashboard
- Product Management
- Search & Filters
- Cart Management
- Order Management
- Razorpay Integration
- Cloudinary Image Uploads

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- JWT
- Cloudinary
- Razorpay
- Nodemailer

## Installation

### Backend

npm install
npm run start

### Frontend

npm install
npm run dev
